# Kontur Code

**Прочтите это первым:** Kontur Code — **инструмент для разработчиков, который пишет в ваши файлы
и запускает программы на вашей машине.** Это и есть продукт, а не дефект. Всё, что ниже сказано
об ограничении возможностей агента — и о каждом известном пробеле, — изложено в
[SECURITY.md](SECURITY.md). Прочтите это, прежде чем направить инструмент на что-то, что вам
дорого.

Настольный LLM-клиент, выросший в **среду пространственной разработки с ИИ**. Одно окно, ваши
собственные API-ключи, ваши переписки в локальном файле SQLite — и рабочая область, которая
превращает указанную вами папку в граф, который действительно видно.

Под окном все слои разделяют два хоста: приложение **WPF** и оболочку **Electron + React** поверх
одного и того же ядра на .NET, поэтому приложение не ограничено потолком ни одного из этих
инструментариев.

## Что он делает

- **Стриминговый чат.** Токены поступают по мере генерации. Остановка сохраняет частичный ответ.
  Повторная генерация заменяет его на месте — при желании на другой модели.
- **Три рабочих режима.** *Chat* — для разговора, *Cowork* — для анализа, *Code* — режим, в
  котором агент получает рабочую область и цикл инструментов. Режим — свойство сообщения, а не
  приложения, поэтому «сначала спланируй, потом собери» — это два сообщения, а не два похода в
  Настройки.
- **Пространственный граф.** Ваша папка автоматически индексируется в узлы и рёбра. Индексатор на
  основе diff'ов добавляет новые файлы, убирает удалённые и **сохраняет расстановку, которую вы
  сделали сами**. Планы, которые выдаёт агент, попадают на холст наборами узлов и рёбер: их можно
  откатить, они сохраняются, и вы вправе их отклонить.
- **Единые поверхности рабочей области.** Холст как карта, граф как структура, дерево файлов,
  редактор, панель git, траектория запуска и представление задач — всё это в одном
  `Ctrl+Shift+P`.
- **Git.** Status, staged и unstaged diff, stage, commit, branch, revert, push, pull, fetch. Всё
  через `git`, **без shell**, с проверкой аргументов.
- **Учёт токенов.** Живое потребление, оценка стоимости и то, что модель на самом деле держит в
  контексте, — вместе с кнопкой **Сжать сессию**, которая складывает более старые шаги в сводку.
- **Рендеринг Markdown.** Заголовки, списки, таблицы, цитаты, списки задач и блоки кода с
  подсветкой синтаксиса. Рендерится как структурированное содержимое, **никогда как внедрённый
  HTML**.
- **Каталог моделей.** Загружается у каждого провайдера и кэшируется в SQLite, поэтому дальше
  выбор модели работает офлайн. Окно контекста, цены и возможности приходят от провайдера, а не
  из жёстко прописанного списка.
- **Два провайдера из коробки** — OpenRouter и NVIDIA NIM, оба совместимые с OpenAI. Направьте
  эндпоинт NVIDIA на локальный Ollama, LM Studio или собственный контейнер NIM — и ничего не
  покинет вашу машину.
- **Пакеты сессий.** Выгружайте всю сессию — чат, холст, файлы, цели — в `.zip`.
- **Три языка.** Английский, русский и немецкий, применяются на лету ко всему интерфейсу.
- **Светлая и тёмная темы**, по системной или закреплённая.

## Агент

Агент работает циклом инструментов, и именно его возможности стоит понять до того, как вы
начнёте им пользоваться.

| | |
| --- | --- |
| **Работает в** | Одной указанной вами папке и отказывается читать или писать за её пределами |
| **Также запрещено внутри этой папки** | `.git`, `.env`, `credentials.json`, `*.pem`, `*.key`, `*.pfx` — по именам, всегда |
| **Спрашивает перед** | Любой записью, любым внешним файлом, любым сетевым запросом, любой программой |
| **Никогда** | Не запускает shell. `&&`, `\|`, `>` и `$HOME` — это текст, который получает программа |
| **Программы** | По умолчанию выключены. Затем только белый список, который правит человек. Затем подтверждение на *каждый* вызов |
| **Откат** | Ваш контроль версий. Изменения показываются до того, как их сделают, а не откатываются задним числом |

Отказ называет нарушенное правило и подсказывает модели, что делать вместо этого, — так что она
перестаёт тянуться к тому же инструменту в третий раз.

**Всё за пределами этой папки включается по желанию и остаётся выключенным, пока вы его не
включите.** Инструмент сетевой загрузки и доступ к файлам вне проекта — отдельные переключатели
в настройках, и каждый вызов всё равно проходит через запрос подтверждения.

> Полная модель ограничения возможностей агента — и **восемь известных пробелов**, включая тот,
> который позволяет junction в Windows обойти правила имён файлов с учётными данными для файлов
> вне проекта, — изложены в [SECURITY.md](SECURITY.md). Это альфа-версия; прочтите документ,
> прежде чем довериться ему.

## Коротко о конфиденциальности

- **Никакой телеметрии. Никакой аналитики. Никаких отчётов о сбоях. Никаких аккаунтов.** В этом
  репозитории нет кода, который открывает соединение с любым адресом, принадлежащим проекту.
- **Ваши переписки не попадают ни на какой сервер.** Это файл SQLite в вашем собственном профиле
  пользователя.
- **API-ключи зашифрованы** средствами Windows DPAPI, привязаны к вашей учётной записи Windows и
  никогда не попадают в журнал.
- **Что покидает вашу машину:** ровно то, что вы отправляете провайдеру модели, и только когда вы
  нажимаете «Отправить». Полный список сетевых адресов — в
  [PRIVACY.md § 5](PRIVACY.md#5-what-leaves-your-machine-and-who-receives-it).
- **Соседние транскрипты читаются и без этого приложения.** База данных не зашифрована при
  хранении — это осознанный компромисс, задокументированный, а не замаскированный.
- **Ваш провайдер модели видит ваш промпт** по *своей* политике, а не по политике этого проекта.
  Это условие, на котором работает клиент для чужой модели.

Подробности, написанные с оглядкой на GDPR, российский 152-ФЗ и CCPA/CPRA, изложены в
[PRIVACY.md](PRIVACY.md). Там же объясняется, как экспортировать данные и как удалить всё.

## Требования

- Windows 10 версии 1809 или новее либо Windows 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download) — только для установщика; для
  запуска уже собранной версии он нужен, для сборки исходников нужен SDK
- API-ключ от [OpenRouter](https://openrouter.ai) или [NVIDIA](https://integrate.api.nvidia.com)
- Около 500 МБ на диске и папка, которую вы готовы доверить агенту на чтение

Кроссплатформенной сборки нет. DPAPI и WPF работают только в Windows, и целевая платформа
говорит об этом прямо, а не падает во время работы.

## Установка

Скачайте установщик со [страницы релизов](https://github.com/rwarx/kontur-code/releases). Это
установка NSIS для одного пользователя — права администратора не нужны.

Первый релиз — **альфа**. Он опубликован потому, что форма уже достаточно устоялась, чтобы
строить поверх неё, а не потому, что он готов к работе без присмотра.

<details>
<summary>Собрать самому</summary>

```bash
git clone https://github.com/rwarx/kontur-code.git
cd kontur-code

# The sidecar has to be published next to where Electron looks for it
dotnet publish src/AIClient.Server -c Release -r win-x64 --self-contained false -o electron/sidecar

cd electron
npm install
npm run dist      # → electron/release/
```

Сборка самого решения на .NET даёт хост WPF:

```bash
dotnet build AIClient.slnx
dotnet run --project src/AIClient.App
```

</details>

## Первый запуск

1. **Настройки → Провайдеры**, вставьте API-ключ, нажмите **Обновить**. Список моделей остаётся
   пустым, пока какой-нибудь провайдер не ответит успехом; дальше каталог кэшируется, и всё
   работает офлайн.
2. **Откройте папку.** В режиме *Code* укажите её на проекте. Папка индексируется в граф, и с
   этого момента мир агента — это и есть эта папка.
3. **Сделайте коммит, прежде чем дать ему работать.** Можно сделать пустой коммит через
   `git commit`. Агент пишет прямо в ваше рабочее дерево — ничего не индексируя и ничего не
   сохраняя на всякий случай; история и есть ваш откат, причём единственный.
4. **Прочтите [SECURITY.md](SECURITY.md)**, если собираетесь включить выполнение команд или доступ
   к файлам вне проекта. Оба выключены по умолчанию, и оба — функции с острыми углами.

## Архитектура

Пять проектов, одно правило: **зависимости направлены внутрь.** `Domain` и `Application`
ориентированы на простую `net10.0`, поэтому обращение к WPF или DPAPI становится ошибкой
компиляции, а не замечанием на ревью.

```text
AIClient.Domain ◄──── AIClient.Application ◄──── AIClient.Infrastructure
                          ▲                          ▲            ▲
                          └──────── AIClient.App ────┘            │
                          └──────── AIClient.Server ─────────────┘
```

```text
provider bytes ──► AIStreamEvent ──► ChatTurnEvent ──► the UI
   (SSE frames)       (Domain)          (Application)    (WPF or React)
```

Три словаря событий, каждый уже предыдущего, переводится на каждой границе. Провайдер не может
засунуть идентификатор базы данных в возвращаемый тип, потому что возвращаемый им тип — не тот
тип, который потребляет интерфейс.

Локальный API требует bearer-токен на каждый запуск процесса и отказывается привязываться ко
всему, кроме loopback: нахождение на `127.0.0.1` не является границей авторизации, и код
обращается с ней как с границей, которой она не является.

Полные рассуждения, включая две двери в файловую систему и два рендерера холста, изложены в
[ARCHITECTURE.md](ARCHITECTURE.md).

## Разработка

```bash
dotnet build AIClient.slnx     # warnings are errors — that is deliberate
dotnet test                    # 896 tests, no network and no API key needed

cd electron
npm install
npm run typecheck
npm run dev                    # renderer against a seeded demo workspace, no backend needed
```

Нужны Windows и .NET 10 SDK. Node 22 нужен только для рендерера.

## Участие в проекте

Мы рады вкладу, и планка проверки для изменений в модели безопасности агента намеренно высока —
потому что этот код умеет писать файлы и запускать программы на вашей машине.

Начните с [CONTRIBUTING.md](CONTRIBUTING.md). Коротко: одно логическое изменение на pull request,
`dotnet test` зелёный, а если вы трогаете возможности агента — укажите в описании, за каким шлюзом
вы его поставили.

Пожалуйста, **не открывайте публичный issue для уязвимости** — о приватном сообщении читайте в
[SECURITY.md](SECURITY.md).

## Состояние

`0.1.0-alpha`. Опубликован как pre-release, намеренно.

**Работает:** стриминговый чат, оба хоста, пространственный граф и холст, цикл инструментов
агента с его шлюзом подтверждения, редактор, git, сессии и пакеты, три языка.

**Известно, что работает плохо** — всё перечислено в
[CHANGELOG](CHANGELOG.md#known-limitations), всё перечислено со ссылками на файлы в
[SECURITY.md](SECURITY.md#known-gaps):

1. Junction в Windows может обойти правила имён файлов с учётными данными для доступа к файлам
   вне проекта.
2. Два подтверждения, пришедших одновременно, могут подвесить запуск вместо того, чтобы провалить
   его.
3. У потока событий нет heartbeat и нет переподключения — разорванное соединение теряет запуск.
4. Редактор пишет на диск на каждое нажатие клавиши, без debounce.
5. Рендерер сохраняет содержимое файлов рабочей области в `localStorage`; большие проекты могут
   превысить квоту браузера.
6. Самые новые поверхности — инструменты внешних файлов, инструмент сетевой загрузки, сервер,
   операции git — не покрыты тестами. Исправления, сделанные для этого релиза, покрыты.

Это версия `0.x` из небольшого проекта без финансирования за спиной. Он собирается открыто, на
задачи отвечают по мере сил, а SLA здесь нет. Если он вам нужен, это разговор с вендором, а не с
этим репозиторием.
