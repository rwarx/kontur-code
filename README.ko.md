# Kontur Code

**먼저 읽어주세요:** Kontur Code는 **사용자의 파일에 쓰기하고 사용자 컴퓨터에서 프로그램을 실행할 수 있는 개발 도구입니다.** 이것은 버그가 아니라 제품 그 자체입니다. 아래에서 설명하는 에이전트의 봉쇄와 알려진 격차들은 모두 [SECURITY.md](SECURITY.md)에 정리되어 있습니다. 소중한 어떤 것에 이 도구를 겨냥하기 전에 먼저 그것을 읽으세요.

데스크톱 LLM 클라이언트에서 **공간적 AI 개발 환경**으로 자란 제품입니다. 창 하나, 사용자의 API 키, 로컬 SQLite 파일에 남는 대화, 그리고 가리키는 폴더를 눈으로 볼 수 있는 그래프로 바꿔 놓는 작업 공간.

창 아래의 모든 계층을 두 개의 호스트가 공유합니다. 같은 .NET 코어 위에 서 있는 **WPF 애플리케이션**과 **Electron + React** 셸입니다. 그래서 어느 쪽 툴킷의 한계에도 묶이지 않습니다.

## 기능

- **스트리밍 채팅.** 토큰은 생성되는 대로 도착합니다. 중단해도 부분 답변이 남습니다. 재생성은 그 자리에서 대체하며, 원하면 다른 모델로 다시 생성할 수도 있습니다.
- **세 가지 작업 모드.** 대화는 *Chat*, 분석은 *Cowork*, 그리고 *Code* — 에이전트에게 작업 공간과 도구 루프가 주어지는 모드입니다. 모드는 앱이 아니라 메시지의 속성이므로 “이것을 먼저 계획하고, 그다음 만들어라”는 설정 화면을 두 번 왕복하는 대신 메시지 두 개로 됩니다.
- **공간 그래프.** 사용자가 가리킨 폴더는 자동으로 노드와 간선으로 색인됩니다. diff 기반 인덱서가 새 파일을 추가하고, 삭제된 파일을 빼고, **사용자가 배치해 둔 레이아웃을 그대로 보존합니다.** 에이전트가 만들어 낸 계획은 노드와 간선의 집합으로 캔버스에 놓입니다 — 실행 취소할 수 있고, 저장되며, 사용자가 거부할 수도 있습니다.
- **통합된 작업 공간 화면.** 지도로서의 캔버스, 구조로서의 그래프, 파일 트리, 편집기, git 패널, 실행의 궤적, 작업 목록 — 모두 `Ctrl+Shift+P` 한 번이면 서로 오갑니다.
- **Git.** 상태, staged와 unstaged diff, stage, commit, branch, revert, push, pull, fetch. 모두 `git`을 통해, **셸 없이**, 검증된 인자로.
- **토큰 사용량 집계.** 실시간 사용량, 예상 비용, 그리고 모델이 지금 컨텍스트에 실제로 들고 있는 것 — 예전 턴들을 요약으로 접어 넣는 **세션 압축** 버튼과 함께.
- **Markdown 렌더링.** 제목, 목록, 표, 인용, 작업 목록, 펜스로 감싼 코드 블록, 구문 강조 포함. 구조화된 콘텐츠로 렌더링되며, **주입된 HTML로는 절대 렌더링되지 않습니다.**
- **모델 카탈로그.** 각 제공업체에서 가져와 SQLite에 캐시하므로, 그 뒤로는 선택기가 오프라인에서도 동작합니다. 컨텍스트 창, 가격, 기능은 하드코딩된 목록이 아니라 제공업체에서 옵니다.
- **기본으로 두 개의 제공업체** — OpenRouter와 NVIDIA NIM, 둘 다 OpenAI 호환. NVIDIA 엔드포인트를 로컬 Ollama, LM Studio 또는 직접 호스팅한 NIM 컨테이너로 향하게 하면 어떤 것도 컴퓨터 밖으로 나가지 않습니다.
- **세션 번들.** 대화, 캔버스, 파일, 목표를 통째로 `.zip`으로 내보냅니다.
- **세 개 언어.** 영어, 러시아어, 독일어를 인터페이스 전체에 실시간으로 적용합니다.
- **라이트와 다크.** 시스템 설정을 따르거나 고정합니다.

## 에이전트

에이전트는 도구 루프를 돌립니다. 그리고 닿는 범위가 바로 사용하기 전에 이해해 두어야 할 부분입니다.

| | |
| --- | --- |
| **작업하는 곳** | 사용자가 지정한 폴더 하나이며, 그 밖을 읽거나 쓰는 것은 거부합니다 |
| **그 폴더 안에서도 거부되는 것** | `.git`, `.env`, `credentials.json`, `*.pem`, `*.key`, `*.pfx` — 이름으로, 언제나 거부 |
| **미리 묻는 것** | 모든 쓰기, 모든 외부 파일, 모든 네트워크 요청, 모든 프로그램 |
| **절대 하지 않음** | 셸 실행. `&&`, `\|`, `>`와 `$HOME`은 프로그램이 받는 텍스트일 뿐입니다 |
| **프로그램** | 기본으로 꺼짐. 켜더라도 직접 편집하는 사람이 관리하는 허용 목록뿐. 게다가 *모든* 호출에 대해 승인 |
| **되돌리기** | 사용자의 버전 관리입니다. 변경은 적용된 뒤에 되돌리는 것이 아니라 적용되기 전에 보입니다 |

거절에는 규칙의 이름이 함께 나오고, 대신 무엇을 해야 하는지가 모델에 전달됩니다. 그래서 같은 도구를 세 번이나 꺼내지 않습니다.

**그 폴더 밖의 모든 것은 옵트인이며, 켜기 전까지는 꺼져 있습니다.** 네트워크 가져오기와 프로젝트 밖 파일 접근은 설정에서 서로 다른 스위치이고, 어느 쪽이든 모든 호출은 여전히 승인 프롬프트를 거칩니다.

> 전체 봉쇄 모델과 **알려진 격차 여덟 개** — 그중 하나는 Windows 정션이 프로젝트 밖 파일에 대한
> 자격 증명 파일 이름 규칙을 무력화할 수 있다는 점입니다 — 는 [SECURITY.md](SECURITY.md)에 있습니다.
> 이건 알파입니다. 믿기 전에 읽으세요.

## 개인정보 요약

- **텔레메트리 없음. 분석 없음. 크래시 보고 없음. 계정 없음.** 이 저장소에는 이 프로젝트가 소유한 어떤 주소로든 연결을 여는 코드가 없습니다.
- **대화는 서버에 닿지 않습니다.** 사용자 프로필 안의 SQLite 파일입니다.
- **API 키는 암호화됩니다.** Windows DPAPI로 암호화되고 Windows 계정에 묶이며, 로그에는 절대 쓰이지 않습니다.
- **컴퓨터 밖으로 나가는 것:** 모델 제공업체로 보내는 것 전부이며, 보내기 버튼을 눌렀을 때뿐입니다. 네트워크 목적지 전체 목록은 [PRIVACY.md § 5](PRIVACY.md#5-what-leaves-your-machine-and-who-receives-it)에 있습니다.
- **연속된 대화 기록은 이 앱 없이도 읽을 수 있습니다.** 데이터베이스는 저장 시 암호화되어 있지 않습니다 — 의도한 절충이며, 덮어두지 않고 문서로 남겼습니다.
- **모델 제공업체는 사용자의 프롬프트를 봅니다.** 적용되는 것은 이 프로젝트의 정책이 아니라 *그쪽* 정책입니다. 남의 모델을 위한 클라이언트가 맺는 계약이 바로 이것입니다.

GDPR, 러시아 152-FZ, CCPA/CPRA를 기준으로 삼아 쓴 세부는 모두 [PRIVACY.md](PRIVACY.md)에 있습니다. 내보내는 방법과 전부 지우는 방법도 함께 설명되어 있습니다.

## 요구 사항

- Windows 10 버전 1809 이상 또는 Windows 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download) — 설치 파일에만 필요합니다. 게시된 빌드는 런타임이, 소스는 SDK가 필요합니다
- [OpenRouter](https://openrouter.ai) 또는 [NVIDIA](https://integrate.api.nvidia.com)의 API 키
- 디스크 약 500MB와, 에이전트가 읽도록 맡길 폴더

크로스 플랫폼 빌드는 없습니다. DPAPI와 WPF는 Windows 전용이며, 타깃 프레임워크가 그 사실을 런타임에 실패하는 대신 미리 알려 줍니다.

## 설치

설치 파일은 [릴리스 페이지](https://github.com/rwarx/kontur-code/releases)에서 받으세요. 사용자 단위 NSIS 설치이며 관리자 권한이 필요 없습니다.

첫 릴리스는 **알파**입니다. 형태가 충분히 굳어 기반 위에 구축할 수 있게 되었기 때문에 공개한 것이지, 무인 운영에 쓸 준비가 되었기 때문이 아닙니다.

## 첫 실행

1. **설정 → 제공업체**에서 API 키를 붙여 넣고 **새로 고침**을 누릅니다. 제공업체 하나가 성공하기 전까지 모델 선택기는 비어 있습니다 — 그 뒤로는 카탈로그가 캐시되므로 오프라인에서도 동작합니다.
2. **폴더를 여세요.** *Code* 모드에서 프로젝트를 가리킵니다. 그 폴더가 그래프로 색인되고, 그때부터 에이전트의 세계는 그 폴더입니다.
3. **작업시키기 전에 커밋하세요.** 비어 있는 `git commit`을 해도 좋습니다. 에이전트는 스테이징된 것도 백업도 없는 채로 사용자의 워킹 트리에 직접 씁니다. 되돌릴 수 있는 것은 사용자의 히스토리뿐이고, 그것뿐입니다.
4. 명령 실행이나 프로젝트 밖 파일 접근을 켜려 한다면 **[SECURITY.md](SECURITY.md)를 읽으세요.** 둘 다 기본으로 꺼져 있고, 둘 다 모서리가 날카롭습니다.

## 아키텍처

다섯 개 프로젝트, 규칙 하나: **의존성은 안쪽을 향합니다.** `Domain`과 `Application`은 순수 `net10.0`을 대상으로 하므로 WPF나 DPAPI를 만지려는 시도는 리뷰 코멘트가 아니라 컴파일 오류가 됩니다.

```text
AIClient.Domain ◄──── AIClient.Application ◄──── AIClient.Infrastructure
                          ▲                          ▲            ▲
                          └──────── AIClient.App ────┘            │
                          └──────── AIClient.Server ─────────────┘
```

```text
provider bytes ──► AIStreamEvent ──► ChatTurnEvent ──► the UI
   (SSE frames)       (Domain)          (Application)    (WPF or React)
```

이벤트 어휘는 셋이고, 갈수록 좁아지며 경계마다 번역됩니다. 제공업체가 돌려주는 타입에 데이터베이스 id를 넣을 수는 없습니다. 돌려주는 타입은 UI가 소비하는 타입이 아니기 때문입니다.

로컬 API는 실행할 때마다 bearer 토큰을 요구하며 loopback이 아닌 곳에는 바인딩하지 않습니다. `127.0.0.1`에 있다는 사실이 인증 경계가 아니며, 코드도 그것을 경계로 다루지 않습니다.

파일 시스템으로 통하는 두 개의 문과 두 개의 캔버스 렌더러까지 포함해 전체 추론은 [ARCHITECTURE.md](ARCHITECTURE.md)에 있습니다.

## 개발

```bash
dotnet build AIClient.slnx     # 경고는 오류입니다 — 의도한 설정입니다
dotnet test                    # 테스트 896개, 네트워크도 API 키도 필요 없음

cd electron
npm install
npm run typecheck
npm run dev                    # 시드된 데모 작업 공간을 대상으로 한 렌더러, 백엔드 불필요
```

Windows와 .NET 10 SDK가 필요합니다. Node 22는 렌더러에만 필요합니다.

중요하면서도 `.editorconfig`로는 표현할 수 없는 규약은 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.

## 상태

`0.1.1-alpha`. 의도적으로 프리릴리스로 공개합니다.

**동작함:** 스트리밍 채팅, 두 호스트 모두, 공간 그래프와 캔버스, 승인 관문이 있는 에이전트 도구 루프, 편집기, git, 세션과 번들, 세 개 언어.

**`0.1.0-alpha` 이후 수정된 것** — 프로젝트 밖 파일이라는 문에서의 보안 결함 두 가지, 그리고 작업 중 데이터를 잃는 방법 두 가지:

- 프로젝트 밖 파일을 읽는 것에 대한 한 번의 승인이 그 실행의 나머지 시간 동안 디스크 전체 읽기 권한을 주었습니다. 이제 프로젝트 밖의 모든 작업은 매번 하나의 질문입니다.
- 프로젝트 밖 경로는 문자열로 검사되고 있었기 때문에, Windows 정션이 자격 증명 파일 이름 규칙을 우회할 수 있었습니다. 이제는 검사하기 전에 링크가 먼저 해석됩니다.
- 편집기는 매 키 입력마다 파일 전체를 기록했습니다. 이제 쓰기는 디바운스되고, **저장 안 됨** 표시와 함께 세션 전환·내보내기·종료 전에 자동으로 기록됩니다.
- 렌더러는 5–10 MB 한도에 대해 모든 파일 본문을 브라우저 저장소에 복제하고 있었고, 가득 차면 **아무 말 없이** 저장이 멈췄습니다. 그 복제는 사라졌습니다.

**아직 남아 있는 것** — 파일 참조를 붙여 [SECURITY.md](SECURITY.md#known-gaps)에 정리: 대화는 저장 시점에 암호화되지 않습니다(의도적입니다. 어차피 Windows 계정에서는 읽을 수 있습니다), 사이드카에는 Kestrel 기본값 외에 요청 크기 제한도 속도 제한도 없습니다, Electron의 main과 preload는 타입 검사를 받지 않습니다, 그리고 가장 최근 에이전트 도구에는 테스트가 없습니다.

뒤에 자금을 두는 사람도 없는 작은 프로젝트의 `0.x` 버전입니다. 공개된 채로 개발되고, 이슈는 최선으로 답하지만 SLA는 없습니다. 필요하다면 그것은 벤더와의 이야기이지 이 저장소와의 이야기가 아닙니다.
