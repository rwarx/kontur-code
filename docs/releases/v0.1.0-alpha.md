## Kontur Code v0.1.0-alpha

**This is an alpha.** It is published because the shape is settled enough to build against, not
because it is ready for unattended use.

### What you need

- Windows 10 version 1809 or later, or Windows 11
- An API key from a provider configured in Settings — the app installs and runs without one; it
  simply cannot talk to a model

### What you get

Streaming chat on two hosts (a WPF application and an Electron shell over the same .NET core), the
spatial graph and canvas, an agent tool loop with an approval gate that defaults to refusing, a
CodeMirror editor with ten language grammars, a git panel, session bundles, and three interface
languages.

### Before you trust it with anything

**This program can write files and run programs.** The agent works inside one folder you nominate
and asks before every change, but that is a description of the intended behaviour, not a guarantee.
Read [`SECURITY.md`](https://github.com/rwarx/kontur-code/blob/main/SECURITY.md) — it explains what
is protected, and it lists **eight known gaps** with file references.

- **Open a folder you are willing to let an agent edit**, and commit your work first. Agent writes go
  straight into your working tree with nothing staged and nothing backed up. Your version control is
  the undo, and it is the only one.
- **Leave command execution and out-of-project file access off** unless a task needs them. Both are
  off by default and both are the features with sharp edges.

### Your data

There is **no telemetry, no analytics, no crash reporting and no account** in this application, and
no server run by this project that your data reaches. Your conversations are a SQLite file in your
own user profile; your API keys are DPAPI-encrypted and scoped to your Windows account.

What leaves your machine is what you send to a model provider, and only when you press Send — under
*that provider's* policy, not this project's. Read [`PRIVACY.md`](https://github.com/rwarx/kontur-code/blob/main/PRIVACY.md),
which enumerates every network destination in the product, and says plainly that consecutive
transcripts are **not encrypted at rest**.

### Known limitations

Six, listed in full in the [`CHANGELOG`](https://github.com/rwarx/kontur-code/blob/main/CHANGELOG.md#known-limitations):

1. A Windows junction can defeat the credential-filename rules for out-of-project file access.
2. Two approvals arriving together can hang a run instead of failing it.
3. The event stream has no heartbeat and no reconnect, so a dropped connection loses the run.
4. The editor writes to disk on every keystroke, with no debounce.
5. The renderer persists workspace file contents into `localStorage`; large projects can exceed the
   browser quota.
6. The newest surfaces — external file tools, the network fetcher, the server, the git operations —
   have no test coverage. The security fixes in this release *are* covered.

### Reporting problems

Security vulnerabilities go through **private reporting**, not a public issue — see
[`SECURITY.md`](https://github.com/rwarx/kontur-code/blob/main/SECURITY.md). Everything else:
[issues](https://github.com/rwarx/kontur-code/issues) and
[discussions](https://github.com/rwarx/kontur-code/discussions).
