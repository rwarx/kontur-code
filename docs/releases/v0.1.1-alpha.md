## Kontur Code v0.1.1-alpha

**Still an alpha.** This release closes what `0.1.0-alpha` documented as gaps. Five of the seven
limitations listed there are fixed; the two that remain are in
[`SECURITY.md`](https://github.com/rwarx/kontur-code/blob/main/SECURITY.md#known-gaps) with file
references.

### What to do

- **If you were on `0.1.0-alpha`: take this one.** It fixes two security holes and two ways of losing
  your work. There is no migration to perform.
- **If you have not installed it yet:** the [full description is here](https://github.com/rwarx/kontur-code#readme),
  and the one that matters is in *What you need* below.

### What you need

- Windows 10 version 1809 or later, or Windows 11
- An API key from a provider configured in Settings — the app installs and runs without one; it simply
  cannot talk to a model

### Security

Two holes in the out-of-project file door, found by re-reading the approval logic against the tool
risk levels rather than trusting the documentation — which had claimed external file access was
"per-call approved". It was not, for reads.

- **One approval used to mean the whole disk.** A remembered approval applies to every tool whose risk
  is not `Execute`, and the external *reads* were declared `Write`. So one answer of "yes" to a single
  read let the agent list `C:\Users\me` and read anything not named in the refusal list. All five
  out-of-project tools are now `Execute`, so **no answer is remembered for them**: one question, one
  read or write.
- **The refusal list could be walked around.** Out-of-project paths were checked as *text*, so a
  Windows junction named `pub` made every requested segment innocent and `.ssh\config` came back out.
  Links are now resolved first, and the refusal list applies to where the path really lands.
- `C:\ProgramData` was missing from the protected system folders while Program Files was present.

### Your work is safer

- **The editor no longer writes the whole file on every keystroke.** It did — a full-file request per
  character, and on a poor connection an error toast per character. Writes are now debounced, with an
  **Unsaved** indicator in the window between your last keystroke and the write, and an automatic flush
  before a session switch, a bundle export or a quit.
- **Local storage will no longer stop saving without telling you.** The renderer was persisting every
  file's text into browser storage, which runs out at around 5–10 MB. When it ran out, the failure was
  silent and *nothing* was saved from then on. File contents are no longer duplicated there — the
  sidecar already holds them — and you will now see a console warning well before the limit.

### Runs survive a dropped connection

A reasoning model can think for minutes before its first token. Nothing was being written during that,
and an idle connection gets closed — so the run ended with no output and no error. There is now a
keepalive every five seconds, and a dropped connection is retried up to three times rather than losing
the run. An approval question can no longer wait forever for an answer that is never coming.

### Smaller dependency surface

45 files and 36 packages that nothing imported have been removed — a UI kit of which three files were
reachable, and the dependencies that went with the rest. Dependencies went from 64 to 28. None of them
were bundled into a build either way, so this is not a size win; it is 36 fewer packages that anyone
running `npm install` pulls into their tree.

### Before you trust it with anything

**This program can write files and run programs.** The agent works inside one folder you nominate and
asks before every change, but that is a description of the intended behaviour, not a guarantee. Read
[`SECURITY.md`](https://github.com/rwarx/kontur-code/blob/main/SECURITY.md).

- **Open a folder you are willing to let an agent edit**, and commit your work first. Agent writes go
  straight into your working tree with nothing staged and nothing backed up.
- **Leave command execution and out-of-project file access off** unless a task needs them.

### Your data

There is **no telemetry, no analytics, no crash reporting and no account**, and no server run by this
project that your data reaches. Your conversations are a SQLite file in your own user profile; your API
keys are DPAPI-encrypted and scoped to your Windows account. What leaves your machine is what you send
to a model provider, and only when you press Send — under *that provider's* policy. See
[`PRIVACY.md`](https://github.com/rwarx/kontur-code/blob/main/PRIVACY.md).

### Reporting problems

Security vulnerabilities go through **private reporting**, not a public issue — see
[`SECURITY.md`](https://github.com/rwarx/kontur-code/blob/main/SECURITY.md). Everything else:
[issues](https://github.com/rwarx/kontur-code/issues) and
[discussions](https://github.com/rwarx/kontur-code/discussions).
